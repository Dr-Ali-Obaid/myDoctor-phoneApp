 ##تطبيق طبيب هو تطبيق يعمل على الهاتف المحمول بنظامي أندرويد و Ios
##يحتوي على واجهة برمجية api تم بناؤها ب node.js من خلال إطار العمل express.js وقاعدة بيانات Postgressql
##ويحتوي على واجهة أمامية تم بناؤها من خلال مكتبة react-native وإطار العمل expo الإصدار 50
##التطبيق يسهل عملية البحث عن الأطباء والحصول على بيانات التواصل معهم:
- يقوم الطبيب بتسجيل حساب يتضمن الاسم والبريد الإلكتروني والتخصص وساعات العمل والهاتف والعنوان كما تتم إضافة موقعه على الخريطة ويستطيع التعديل على هذه البيانات بعد ذلك باستثناء البريد الإلكتروني
- يقوم المستخدم العادي بتسجيل بيانات الاسم والبريد الإلكتروني 
- يتمكن جميع المستخدمين من تصفح قائمة الأطباء المسجلين والبحث عنهم من خلال الاسم وعرض التفاصيل المتعلقة بهم
##لتشغيل التطبيق:
##قم بتحميل الملفات
##في مجلد server في ملف .env قم بالتالي:
- DB_PASS = أدخل كلمة مرور قاعدة البيانات الخاصة بك على postgressql
- JWT_SECRET = أدخل مفتاح التشفير الذي ترغب فيه
##الدخول على مجلد الواجهة البرمجية (server) ثم تثبيت الاعتماديات من خلال الأمر npm install ثم تشغيل الخادم من خلال الأمر npm start
##الدخول على مجلد واجهة التطبيق (client) ثم تتثبت الاعتماديات من خلال الأمر npm install ثم تشغيل التطبيق من خلال الأمر npx expo start ثم مسح الباركود من خلال برنامج expo بعد تثبيته على الجوال 
##يجب أن تكون نسخة برنامج expo المثبتة على الجوال هي النسخة رقم
